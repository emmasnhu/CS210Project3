# CS210Project3
This was my submission for my third project in SNHU's CS210 C++ programming class. 
# Summarize the project and what problem it was solving.
This project's objective was to create an item-tracking program for a grocery store known as "Corner Grocer: It needed to analyze text records and list records in chronological. The problem to solve was for the company to be able to better tell how to rearrange their produce section for the most effective layout. 
# What did you do particularly well?
I think something I did particularly well was with my file management. I made sure to create different files for class declarations, definitions, and the main file. I also think I did a good job in opening, reading, and closing the grocery file. 
# Where could you enhance your code? How would these improvements make your code more efficient, secure, and so on?
In this project, something I got points docked on was not accounting for capitalization in menu option one. So, I would enhance my code by adding a system that also allows capitalization when searching through the file. This would help user improvement because instead of the program saying the item does not exist when they type in lowercase, it would still show the items. Not every user will type in perfect grammar and syntax so it's important to account for that. I'm sure it will also help prevent other errors from occurring. 
# Which pieces of the code did you find most challenging to write, and how did you overcome this? What tools or resources are you adding to your support network?
This was my first time using maps, so I would definitely say that part was the most challenging to write. I overcame this by watching tutorials online. I found a channel called "Tech With Tim" that I will continue to reference in the future. 
# What skills from this project will be particularly transferable to other projects or course work?
I think the skills of knowing what to put into the main function and what to put into different classes will be easily transferable into future projects and course work. 
# How did you make this program maintainable, readable, and adaptable?
I made this program maintainable by working at it in small parts. I started with my declarations, then to definitions, then to the main function and still split each of those things into even smaller portions. I made it readable and adaptable by including comments explaining each section of my code and using easily identifiable function and variable names along with camel case so they are easy to read.
